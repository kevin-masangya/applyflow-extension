# Applyflow extension

Public Chrome extension only. The Applyflow application source is not in this repository.

1. Download [applyflow-extension.zip](https://github.com/kevin-masangya/applyflow-extension/raw/main/applyflow-extension.zip).
2. Unzip it.
3. Open chrome://extensions and turn on Developer mode.
4. Drag the `applyflow-extension` folder onto that page.
5. Open the side panel and choose Connect account.
